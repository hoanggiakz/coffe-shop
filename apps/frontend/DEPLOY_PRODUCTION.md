# Frontend deploy (production)

## 1) Frontend env
Copy `apps/frontend/.env.example` to `.env` when building frontend.

Recommended values:
- `VITE_API_URL=/api`
- `VITE_WS_URL=` (empty => use same-origin)

## 2) Build image
From `apps/frontend`:

```bash
npm run build
```

Or Docker build:

```bash
docker build -t coffee-frontend:prod .
```

## 3) Run container

```bash
docker run -d --name coffee-frontend -p 80:80 coffee-frontend:prod
```

Container nginx already proxies:
- `/api` -> `http://api-gateway:8080`
- `/socket.io/` -> `http://chat-service:3007`

## 4) TLS/HTTPS
Current frontend container is HTTP-only. Terminate TLS at your edge proxy/load balancer (Cloudflare, Nginx, Traefik, ALB, etc.).

## 5) Required backend env for QR
To ensure QR opens the real customer page, set at backend runtime:
- `APP_BASE_URL=https://your-domain.com`

QR will point to:
- `https://your-domain.com/menu?tableId=...&tableNumber=...&branchId=...`
- `tableId` should be the table record ID (UUID generated by table-service), not only the visible table number.

## 6) CORS
If frontend and API are same-origin through gateway, keep default.
If cross-origin, add frontend domain into `ALLOWED_ORIGINS`.
