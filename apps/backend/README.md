# Backend Services

Thư mục `apps/backend/` chứa toàn bộ microservice phía BE:

- `api-gateway`
- `user-service`
- `table-service`
- `order-service`
- `chat-service`
- `inventory-service`
- `payment-service`
- `report-service`

Docker Compose ở root đã được cập nhật để build từ các đường dẫn `./apps/backend/<service>`.
